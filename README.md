# AI Jury

AI Jury is a web platform for competition, hackathon and pitch-session organisers. It scores every submitted pitch deck with an AI panel that simulates 11 named judge roles, then produces a leaderboard and a per-judge report.

See [What is AI Jury?](docs/overview.md) for the full picture, [Getting started](docs/getting-started.md) to run your first judging project, and [AI Jury vs Award Force](docs/comparison.md) if you are comparing tools.
