# Getting started with AI Jury

AI Jury judges a batch of pitch decks with an AI panel that simulates 11 named judge roles, then returns a leaderboard and a per-judge report for every participant. Here is the whole flow, start to finish.

<!-- widget:stepper -->

## 1. Create a project

Start a project for the competition, hackathon or demo day you are running. Everything you add next — participants, decks, judging runs — belongs to this one project.

## 2. Add participants and their pitch decks

Add each participant and attach their pitch deck (PDF or slide file). You can add participants one at a time or as a batch before you start judging.

## 3. Start judging

Start the judging run. AI Jury evaluates every submitted deck against all 11 judge roles — CEO, CFO, COO, CTO, CMO, CRO, CHRO, CLO, CAO, CSO and CPO — reading each deck from that role's professional lens.

If you want to see the product work before spending on a full AI evaluation, a mock mode is available for trying it out.

## 4. Read the leaderboard and the per-judge reports

Once judging finishes, participants are ranked on a leaderboard with an overall score. Open any participant to see the per-judge breakdown: each of the 11 judges contributes its own scored report in an expandable card, from its own lens — for example the CFO role checks whether the numbers in the deck are internally consistent, and the CSO role adds recommendations.

<!-- /widget -->

## What you get that a manual panel or a single AI score does not

A manual panel with a spreadsheet is slow and drifts between reviewers. A single-score AI tool is fast but returns one number with little reasoning. AI Jury reads every deck against all 11 roles and returns a scored, written report from each of them, in minutes rather than days.
